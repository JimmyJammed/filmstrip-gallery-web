# Contributing

Use Node 22.18+ and `npm ci`. Open a focused branch and PR describing observable behavior and local checks. Run lint, build, unit tests, clean consumer verification, and browser tests. Add a regression test for behavior fixes.

Preserve MIT and dependency notices, keyboard access, reduced-motion/Save-Data behavior, neutral sample content, and teardown. Do not add automatic Actions workloads, telemetry, or private media. Keep core framework-neutral and React optional. For UI changes include desktop/mobile previews and relevant validation evidence.
